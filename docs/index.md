# Naviox documentation

Naviox lets your app search commands, browse nested pages, and run actions. The core is headless: it does not draw the menu or decide how your router works.

## Start here

- [Getting started](getting-started.md) — create your first command list and connect your UI.
- [Configuration](configuration.md) — search behavior, keyboard shortcuts, groups, providers, and state.
- [Examples](recipes.md) — practical patterns for navigation, remote search, and cleanup.

## Go deeper

- [Public API overview](public-api.md) — quick index of exported functions.
- [Extensions](extensions.md) — add commands and providers without coupling modules.
- [How it works](architecture.md) — what belongs in the core versus your app.
- [Compatibility](compatibility.md) — JavaScript, TypeScript, and Node support.
